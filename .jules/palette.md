## 2024-05-18 - Safe Async UI Spinners and ARIA Toggles
**Learning:** Adding dynamic HTML like loading spinners to existing text elements should never use `innerHTML` blindly with string concatenation, as this can introduce XSS risks or require hallucinated `htmlEscape` functions. Additionally, global CSS specificity issues mean `input[type="range"]` and `.pill` elements often lose base styles when applying new `:focus-visible` or programmatic classes.
**Action:** When adding inline spinners, always use native `document.createElement()` and `appendChild()` patterns combined with `scale()` transforms instead of new custom inline CSS classes. Ensure button toggles correctly map semantic classes (`active`) directly to stateful ARIA attributes (`aria-pressed`).
