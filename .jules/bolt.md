## 2025-04-10 - [PyTorch Fourier Features Vectorization] **Learning:** Iterating over tensors and appending PyTorch operations iteratively to lists (`for scale in scales: feats.append(...)`) is slow. By broadcasting dimensions using `unsqueeze`, we can perform operations simultaneously. Interleaving `sin` and `cos` features can be elegantly done by combining `torch.stack` and `.view()`. **Action:** Always look for opportunities to replace `for` loops with vectorized PyTorch operations using dimension broadcasting, stacking, and reshaping.
