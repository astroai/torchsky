# Security policy

## Supported versions

Security fixes are made on the latest released minor version and on `main`.

## Reporting a vulnerability

Please do not open a public issue for security problems. Use GitHub private
vulnerability reporting: open the **Security** tab of
[astroai/torchsky](https://github.com/astroai/torchsky/security) and choose
**Report a vulnerability**.

Include the affected version, a minimal reproduction, and the impact you
expect. We aim to acknowledge reports within a few days and will coordinate a
fix and disclosure timeline with you.
