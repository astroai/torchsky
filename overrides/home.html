Astro compute for PyTorch

Tensor-native coordinates, HEALPix, mapmaking, and differentiable sky models — CPU, CUDA, and Apple Silicon.

Quick start Install WCS Mapmaking API 
import torch
from torchsky.wcs import WCS
import torchsky.sphere as sphere

wcs = WCS(header)  # header: a plain dict, e.g. from torchfits
x = y = torch.arange(0.0, 512.0, 64.0)
ra, dec = wcs.pixel_to_world(x, y)
pix = sphere.ang2pix(1024, ra, dec, lonlat=True, nest=True)
