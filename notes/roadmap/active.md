# Core implementation status

This file tracks torchsky-owned implementation work only. It does not track
scientific campaigns, comparator runs, CANFAR jobs, or acceptance status; those
records live in
[`torchsky-harness`](https://github.com/astroai/torchsky-harness).

There is no package-wide active campaign queue here. For a code change, keep
the working plan in its issue or review, preserve unrelated local changes, and
update the relevant runtime guide and bounded tests. Follow the priorities and
verification policy in [`AGENTS.md`](../../AGENTS.md).

The current package architecture and implementation priorities are summarized
in [status.md](status.md) and [next.md](next.md). The full prior roadmap snapshot
is retained in the harness staging archive at
`docs/archive/core-before-second-pass/docs/roadmap/active.md`.
